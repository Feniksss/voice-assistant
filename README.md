# Голосовой ассистент на OpenAI Realtime API (WebRTC)

Речь пользователя уходит напрямую в OpenAI по WebRTC, оттуда же приходит
голос ассистента. Своего STT/TTS в проекте нет — всё делает одна модель.

## Запуск

1. `npm install`
2. Скопируйте `.env.example` в `.env` и впишите свой ключ OpenAI.
3. `npm start`
4. Откройте http://localhost:3000

Микрофон в браузере работает только на `localhost` или по HTTPS.

## Что где

- `server.js` — меняет постоянный API-ключ на короткоживущий client_secret.
  Постоянный ключ в браузер не попадает. Здесь же задан промпт ассистента.
- `public/app.js` — WebRTC-соединение, микрофон, приём голоса, транскрипты.
- `public/index.html` — интерфейс.

## Что настраивать в первую очередь

- **Промпт** (`INSTRUCTIONS` в `server.js`) — сильнее всего влияет на то,
  насколько живой получается речь.
- **Голос** (`voice`) — доступны варианты вроде marin, cedar, alloy, verse.
- **turn_detection** — `semantic_vad` решает по смыслу фразы, `server_vad`
  по тишине. Для русского semantic обычно точнее.
- **Модель** — по умолчанию флагман `gpt-realtime-2`. Дешевле —
  `gpt-realtime-2-mini`, для большинства диалогов её хватает. Менять
  можно через `.env` (`REALTIME_MODEL`, `REALTIME_VOICE`,
  `REALTIME_TRANSCRIBE_MODEL`), не залезая в код.
